      All messages are synthetic and fictional. Signal Aid is a support tool for volunteers and does not replace civil protection authorities.

      How Signal Aid works

      1. Every message gets four typed questions from Strands Decider 2B, in a single call: what it reports, whether the author is there in person, how urgent it is, and whether people are in danger.
      2. Plain code routes it with asymmetric thresholds. Harmless messages are handled automatically. Anything that may involve a person in danger is never auto-handled: it is published if Decider is confident, or sent to a human.
      3. Only actionable messages reach Amazon Bedrock. A Strands agent writes the incident brief and decides whether to publish a new incident or merge into a nearby one.
      4. Decider gates the agent's tool calls. A Strands InterventionHandler lets a merge happen only if Decider says both reports describe the same incident.

      Read a decision from top to bottom: the verdict first, then the message, then the evidence behind it.
